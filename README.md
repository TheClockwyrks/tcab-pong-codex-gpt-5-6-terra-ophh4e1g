# Carom

Carom is a browser-based top-down paddle duel. Curve a fast ball with paddle spin, bank it through the center blockers, and be the first to win by two at eleven points.

## Run it

Install dependencies with `npm ci`, then start a development server with `npm run dev`. Build the self-contained static site with `npm run build`; the result is written to `dist/` and can be served by any static web server.

## Controls

- Player one: `W` / `S`
- Player two (Versus): `Up` / `Down`
- Menus: `W` / `S` or arrow keys, `Enter` / `Space`
- Pause: `P` or `Escape`; mute: `M`

In Solo, either set of movement keys controls the cyan paddle. Move while striking the ball to add spin and bend its flight.
